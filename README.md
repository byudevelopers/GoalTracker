# GoalTracker

A simple goal tracking app built with Flutter and Dart. Users can create, manage, and mark goals as completed. Designed to be lightweight and easy to use.

## Features

- ✅ Add and edit goals
- 📆 View active and completed goals
- 🎯 Mark goals as done
- 🧼 Clean and minimal UI
